# PAUSE · Neumorphism

Un pequeño dispositivo de respiración y concentración.

Demo bilingüe conceptual, adaptable a móvil. Código en src/main.jsx y src/style.css.

Desde la raíz del repositorio: npm.cmd install y npm.cmd run dev. Abre http://127.0.0.1:5180/Neumorphism/ o selecciona el proyecto en el catálogo.
