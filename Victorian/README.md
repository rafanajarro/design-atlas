# THE FERN SOCIETY · Victorian

Un gabinete botánico de láminas y cartas.

Demo bilingüe conceptual, adaptable a móvil. Código en src/main.jsx y src/style.css.

Desde la raíz del repositorio: npm.cmd install y npm.cmd run dev. Abre http://127.0.0.1:5180/Victorian/ o selecciona el proyecto en el catálogo.
