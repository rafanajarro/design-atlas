# TSUCHI · Wabi-Sabi

Un pequeño taller de cerámica y objetos imperfectos.

Desde la raíz del repositorio: npm.cmd install y npm.cmd run dev. Abre http://127.0.0.1:5180/Wabi-Sabi/ o selecciona el proyecto en el catálogo.
